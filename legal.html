Methodology

ChartLens is an educational market-structure tool. It does not place trades, connect to a brokerage, manage money, or provide personalized financial advice.

Screenshot mode processes the uploaded image in the browser using canvas/pixel heuristics. It looks for high-contrast structure, left-to-right slope, and approximate reaction zones. The screenshot is not uploaded by the current app.

Live mode sends ticker, market, interval, and provider parameters to the ChartLens Cloudflare Worker market-data proxy. The Worker fetches candle data from external market-data providers, returns normalized candles, and the browser renders the chart image locally before running the same visual scan.

The generated brief is a visual heuristic. It is not a prediction, recommendation, rating, research report, investment advisory service, or guarantee of future price movement.

Privacy

Without login, workspace data is stored locally in your browser. With login, analyses, favorites, and trackers are saved to Firebase Firestore under your authenticated user ID.

Firebase Authentication is used for Email/password and Google Sign-in. Google authentication is optional; Email/password is available as a fallback.

Screenshot mode does not upload the selected image in the current implementation. Live ticker mode sends market lookup parameters to the Cloudflare Worker and external market-data sources may receive request metadata from the proxy.

Do not upload screenshots containing account numbers, balances, personal identifiers, broker names, order IDs, or other sensitive information.
